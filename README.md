### Branches principales

**main** correspond à la version de **production**.

**develop** à la **préproduction**.

### Nomenclature des branches :

Le projet utilise une nomenclature des branches selon le format **type/description-courte**.

**feature/** sont utilisées pour développer les User Stories : **feature/us\[xx]-description**

**fix/** pour corriger les bugs.

**ci/** les modifications liées à l'intégration et au déploiement continus.

Les noms des branches sont écrits en minuscules, sans accents ni espaces, les mots sont séparés par des tirets.

### Nomenclature des commits :

**feat:** ajout d'une fonctionnalité

**fix:** correction d'un bug

**refact:** amélioration du code sans modification de son fonctionnement

**test:** ajout ou modification de tests

**docs:** ajout ou modification de documentation

**ci:** modification de l'intégration ou du déploiement continus

**chore:** maintenance et configuration du projet
